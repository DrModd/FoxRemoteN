# Fox Remote

Android-пульт для сетевого плеера на **PureFox** (Luckfox Pico Max).

- поиск Фокса в сети (mDNS), либо ручной ввод адреса;
- выбор плеера: Qobuz Connect, HQPlayer NAA, Roon Ready, AirPlay, Spotify, Squeezelite, UPnP, MPD, веб-радио…;
- переключение СЕТЬ / USB → I2S;
- громкость (ползунок и кнопки громкости телефона), mute;
- частота и формат потока — если на Фокс положен `extras/rate.php`.

Работает через те же запросы, что и веб-интерфейс PureFox, — прошивку менять не нужно.

## Сборка без Android Studio (GitHub Actions)

1. Создать на GitHub пустой репозиторий (можно приватный).
2. Залить в него содержимое этой папки (кнопка «uploading an existing file» → перетащить все файлы и папки, включая `.github`).
3. Вкладка **Actions** → сборка запустится сама (~5 мин).
4. Готовый APK: вкладка **Releases** → «FoxRemote (последняя сборка)» → `FoxRemote.apk`.
   Удобно открыть эту страницу прямо с телефона.
5. На телефоне разрешить установку из этого источника и установить.

Каждое изменение в репозитории пересобирает APK. Подпись постоянная (`app/debug.keystore`),
поэтому новая версия ставится поверх старой.

## Сборка в Android Studio

Открыть папку проекта → Run. Нужен JDK 17 (идёт со Studio).

## Частота потока (необязательно)

Скопировать `extras/rate.php` на Фокс:

    scp extras/rate.php root@purefox.local:/var/www/rate.php

(пароль `purefox`). После обновления прошивки PureFox файл может пропасть — повторить.
